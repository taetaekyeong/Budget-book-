# 📒 식비 가계부

월급날 기준으로 한 달 식비를 기록하고, 남은 예산과 하루 권장 지출액을 확인하는 모바일 웹앱입니다.
서버 없이 **HTML 파일 하나**로 동작하며, 데이터는 내 기기 브라우저에만 저장됩니다.

## 주요 기능

- **월급날 기준 주기**: 월급날(기본 25일)부터 다음 월급 전날까지를 한 주기로 계산
- **총 예산 설정**: 주기별 식비 예산을 직접 지정 (기본 40만원)
- **하루 여러 건 입력**: 아침·점심·저녁 등 식비를 건별로 추가/삭제
- **무지출 표시**: 지출 없는 날을 따로 구분
- **평일/주말 가중 권장액**: 주말 가중치를 반영해 남은 기간의 하루 권장 지출액 안내
- **현재 페이스 예상**: 지금 속도로 쓰면 주기 말 총지출이 얼마일지 예측
- **연간 개요**: 월별 요약을 보고 눌러서 해당 주기로 이동
- **몬테카를로 연동**: 입력한 기록에서 하루 식비 범위를 자동 추정해 예산 초과 확률 시뮬레이션

## 사용 방법

1. 오른쪽 위 **⚙ 설정**에서 월급날과 총 예산을 입력합니다.
2. 날짜를 고르고 금액을 입력한 뒤 **추가**를 누릅니다. (여러 건 가능)
3. 지출이 없었던 날은 무지출로 표시합니다.
4. **◀ ▶** 로 주기를 이동하며 지난 기록을 확인합니다.
5. 하루 권장액과 현재 페이스를 보며 남은 예산을 조절합니다.

## 설정 항목

| 항목 | 설명 |
|---|---|
| 월급날 (일, 전 주기 공통) | 주기 시작일 |
| 총 예산 | 이번 주기 식비 예산 |
| 주말 가중치 (평일 대비 배) | 주말 하루 권장액을 평일의 몇 배로 볼지 |
| 평일 / 주말 하한~상한 | 몬테카를로 시뮬레이션의 하루 식비 범위 |
| 기록으로 자동 추정 (10~90%) | 입력 기록의 분위수로 범위를 자동 설정 |
| log 보관 개수 (0=무제한) | 폴더 저장 시 유지할 백업 파일 수 |

## 저장과 백업

- 입력 내용은 **자동으로 브라우저(localStorage)에 저장**됩니다.
- **💾 저장**: 백업 JSON 파일을 만듭니다.
  - PC(Chrome/Edge): 선택한 폴더의 `log/` 안에 자동 저장
  - iPhone(Safari): 파일이 **다운로드**됩니다. 파일 앱에서 iCloud Drive 등으로 옮겨 보관하세요.
- **📂 불러오기**: 백업 JSON을 선택해 복원합니다. 복원 직전 데이터는 자동으로 한 번 보관됩니다.

> 브라우저 데이터를 지우거나 기기를 바꾸면 기록이 사라지므로, 가끔 **💾 저장**으로 백업하세요.

## iPhone에서 사용하기

1. **Safari**로 배포 주소(GitHub Pages)를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**.
3. 이후에는 **홈 화면 아이콘으로만** 실행합니다. (Safari 탭과 저장소가 분리됩니다)

## 배포 (GitHub Pages)

1. 저장소에 `index.html`과 `README.md`를 올립니다.
2. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 설정합니다.
3. 발급된 주소 `https://<아이디>.github.io/<저장소명>/` 로 접속합니다.

> 저장소 이름(주소)을 바꾸면 저장 공간이 새로 잡혀 기록이 비어 보입니다. 바꾸기 전에 반드시 백업하세요.
